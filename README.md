# ウォーターソートパズル

試験管20本以上、エンドレスで遊べるウォーターソート。iPhone のダブルタップ拡大対策済み。

## GitHub Pages で公開する手順
1. GitHub で新しいリポジトリを作成（Public）
2. `index.html` をリポジトリ直下にアップロード（`.nojekyll` と `README.md` は任意）
3. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます
